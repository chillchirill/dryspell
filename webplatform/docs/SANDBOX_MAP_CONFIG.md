# Configuring the geographic adapter

The sandbox uses `MAP_API_ORIGIN`, defaulting to `http://127.0.0.1:4180` as documented by the V2 geographic handoff. Set it in the process environment when using another existing provider. Both old4177 and new4180 responded locally during this revision; the integration now prefers4180. Existing services are not restarted or migrated. The sandbox continues to bind only127.0.0.1:4001.

Rendered derivatives identify palette `dryspell-natural-v2` in client URLs, response headers and ETags. Raw classified cells and simulation checksums are independent of this display version. Existing source byte caches and map database contents are untouched.
