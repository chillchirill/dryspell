# Daily TensorFlow baseline pipeline

Status: pipeline implemented; real historical training/evaluation not completed. No trained or promoted production artifact is claimed. Node 24 with pure-JavaScript @tensorflow/tfjs CPU is the selected fallback; native tfjs-node/Ubuntu compatibility is unverified. The [TensorFlow Node guide](https://www.tensorflow.org/js/guide/nodejs) was read on 2026-11-14; training/inference belongs outside HTTP handlers.

## Real benchmark access

The official [Google Research source README](https://github.com/google-research/google-research/tree/master/simulation_research/next_day_wildfire_spread) links the [Huot et al. dataset](https://www.kaggle.com/datasets/fantineh/next-day-wildfire-spread) and an Earth Engine export workflow requiring the operator's Cloud Storage bucket. Public Kaggle file listing was reached with HTTP on 2026-11-14. It includes an evaluation shard of 213,313,000 bytes and another of 187,075,501 bytes. A bounded HTTP 206 range read of bytes 0–262143 from the individual train_00 ZIP succeeded; the server declared 120,535,393 total bytes. Stream inflation parsed the first 213,297-byte Example: all 13 published float fields had 4,096 pixels each; no event, date, or coordinate metadata was present. This verifies bounded data access and the converter schema, not a completed corpus download or training run. Official constants.py and dataset.py were also read to verify specific-humidity/Kelvin units and unknown-label masking. No public gs bucket URL was found in those official sources. A referenced demo notebook URL returned 404.

Exact missing prerequisites: downloaded train/validation/test TFRecord shards with their distribution licence; independently sourced per-chip complete-fire-event, geographic block and temporal block metadata; matching-scale physical forecast values for the required physical-baseline comparison; an authorized Earth Engine/Cloud Storage export project if generating georeferenced replacements. Do not invent event IDs or coordinates from arbitrary chip numbers and call that leakage-safe validation. VIIRS regional fire-mask/geolocation/QA data and matching historical forecast issue-time datasets are also not supplied.

## Pipeline

`python packages/inference/convert_benchmark.py input.tfrecord chip-metadata.json output.jsonl` streams Examples without requiring TensorFlow Python. A metadata map keyed by record index must give eventId, geographicBlock, timeBlock, split (train/validation/test), region and fuel. The converter rejects absent identities, unknown fire labels and invalid feature values. Specific humidity stays kg/kg; it is not relabelled as relative humidity. The named subset preserves published features without fabricating unavailable coordinates. The converter verifies masked CRC32C for TFRecord lengths and payloads, and emits a source SHA-256 and feature/target manifest. Known-vector, valid-record and corrupted-record checks passed with `python tests/integration/converter_check.py`; source checksums must also match trusted manifests before conversion.

`npx tsx packages/inference/src/train-cli.ts rows.jsonl manifest.json data/models/daily-baseline` trains a seeded 32-ReLU/16-ReLU/sigmoid network with minibatches, class balancing, L2 regularization and early stopping. Input loading is bounded to 500,000 rows; use curated whole-event shards within that bound. Normalization is fitted only to train; sigmoid calibration and physical blending coefficient are fitted only to validation; final metrics use test once. Complete-event IDs and geographic blocks may not cross partitions. The regional converter additionally requires disjoint issue-month blocks. The split validator does not independently prove geographic separation; the dataset producer must supply separated blocks and provenance.

Outputs: TensorFlow topology/weights, feature schema and normalizer, seed, dataset checksum, source manifest, calibration, daily scale/domain metadata, model card, precision/recall, PR-AUC, Brier, reliability bins and per-region/fuel breakdown. Persistence and logistic baselines are evaluated; physical comparison is explicitly unavailable unless matching-scale probabilities were supplied. Blend alpha is selected only if validation physical probabilities exist. No automatic promotion occurs. A trained model remains experimental until domain/calibration/baseline review.

Runtime fallback distinguishes missing artifact, unpromoted model, unsupported domain and scale/horizon mismatch. The local ensemble remains active. The 1 km / 24 h neural target never silently replaces 25 m / minute fire predictions. TensorFlow model loading and synthetic smoke tests establish engineering compatibility only; they do not establish real-data accuracy.

## Runtime and executed compatibility evidence

Contract1.1.0 exposes lazy predictDailyBaseline from @dryspell/inference. It loads metadata and TensorFlow artifacts, enforces promotion, exact validated domain, 1 km/daily target, feature cardinality/finite values and physical-grid alignment, then applies trained normalization/calibration and validation-selected blend. Any unavailable/corrupt/incompatible model returns the supplied physical probabilities and an explicit fallback reason; it never manufactures missing features. Detailed predictFireSpread requests with modelVersion check DRYSPELL_MODEL_DIR/DRYSPELL_MODEL_DOMAIN and expose the concrete fallback. The detailed input deliberately does not synthesize population/ERC/specific-humidity features; daily predictions require their actual matrix. The backend provides an authenticated bounded daily prediction job route, executed by the analysis worker; see API.md. The normalized coverage-aware regional converter is implemented and fixture-tested; see [REGIONAL_DATASET.md](REGIONAL_DATASET.md). Raw VIIRS collection decoding, automated provider-derived daily feature acquisition and a real regional corpus remain incomplete.

Executed software test: CPU TensorFlow trained two epochs on 36 explicitly synthetic rows, exported and reloaded the model, produced finite probabilities, and rejected unpromoted/out-of-domain/wrong-scale usage. The temporary test-only promoted metadata/artifact was deleted after testing. No production model was promoted; real historical training and evaluation remain externally blocked as described above.
