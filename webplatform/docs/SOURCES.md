# Environmental acquisition and provenance

Reviewed 2026-11-14. Contract 1.1.0. Sources are separate from basemap tiles and never inferred from display colours.

## Executed acquisition

`data/sample/environment.json` contains an actual 5 km × 5 km area in Glendalough, County Wicklow, Ireland, represented by 200 × 200 cells at 25 m. Source rows were reversed from TIFF north-to-south into the domain's south-to-north row order. Land cover is ESA WorldCover 2021 v200, nominal 10 m; elevation is Copernicus DSM GLO-30 2021, nominal 30 m. Derived slopes use centered elevation differences. SHA-256 of the effective grid: `9b9d9c7ba15f2ee538acdc3541273e4b99e47cc9745d0c3283149cd887b0c8f9`.

Acquisition used GeoTIFF HTTP ranges with a 64 KiB bounded block cache. Native Node HTTPS timed out on this Windows host; the opt-in `DRYSPELL_WINDOWS_HTTP=1` helper used the Windows HTTP stack against the two allowlisted raster hosts. It does not permit arbitrary endpoints or full-file fallback. No worldwide archive was downloaded. The resulting grid includes grass, woodland, water, scrub, built and explicitly unknown cells. Weather is a clearly identified synthetic dry westerly example; it is not represented as a real 2026 observation. Fuel mappings/rates are illustrative assumptions and are documented in the modelling notes.

Reproduce acquisition: `npx tsx packages/data-sources/src/prepare-sample.ts` (on this Windows proxy configuration, first set `DRYSPELL_WINDOWS_HTTP=1`). Ordinary installation uses the retained redistributable sample and does not need to redownload it. Exact source URLs, retrieval timestamps, checksums, parameter bounds and attribution are in `data/sample/manifest.json`. Licence notices are in `data/sample/LICENSES.md`.

## Adapters and availability

- Open-Meteo forecast, historical archive and Single Runs request adapters use explicit Celsius, percent RH, m/s, mm and UTC. Missing values reject snapshot creation. Requests have bounded attempts/timeouts and cancellation. The actual forecast adapter successfully fetched 24 hourly samples on this host through the opt-in Windows transport; evidence is retained as data/sample/verified-live-weather.json. The historical adapter also successfully retrieved 24 hourly samples for 2026-11-01 (verified-historical-weather.json). The Single Runs adapter retrieved an ECMWF IFS run initialized 2026-11-01T00:00 (verified-single-run-weather.json): 23 complete hourly samples begin at 01:00 because the initial precipitation accumulation is unavailable. That incomplete leading hour was excluded and reported in provenance, never changed to zero. Interior missing hours reject the snapshot.
- NASA FIRMS VIIRS SNPP area CSV adapter validates bounded date ranges, splits antimeridian requests, preserves observation and receipt time, and reports approximate 375 m resolution. `FIRMS_MAP_KEY` is absent; no live FIRMS request is claimed successful. Satellite points are not perimeters and confidence categories are not calibrated probabilities.
- ESA WorldCover and Copernicus COG windows were successfully acquired for the retained fixture. New area preparation mosaics adjacent source tiles and creates an immutable snapshot. The area preparer accepts 250–10000 m areas and up to 400 cells per edge. Polar centers beyond ±85° are explicitly unsupported, not silently approximated. Small local grids use a declared local azimuthal-equidistant projection with lat/lon rectangular indexing; metric approximation limits remain relevant at high latitude.
- OSM Overpass supplementary features: first live attempt returned HTTP 406; a second mirror timed out after 40 seconds. Adapter exists, but successful live enrichment is unverified. Missing OSM tags never imply grass or no vegetation.
- Data jobs retain errors/retry counts. Imported weather/OSM results are cached in PostgreSQL; successful terrain preparation writes an immutable environmental snapshot. Cache rows have retrieval and expiry times. The current adapters do not automatically substitute expired weather as fresh.

## New areas and explicit overrides

Administrator `POST /api/v1/environment/prepare` accepts `{center:{longitude,latitude},sizeM?,cellSizeM?,date?,weatherOverride?}`. It returns a leased job ID. Poll `/api/v1/jobs/:id`; completed jobs expose `environmentId`, which can be selected while creating/editing a scenario. Without `weatherOverride`, preparation requires actual weather acquisition. Override weather is labelled administrator-supplied. Failed providers leave the job failed with its exact reason, rather than manufacturing complete coverage.

`POST /api/v1/scenarios/:id/inputs` accepts the expected revision, optional weather sample and optional per-cell fuel changes. It creates a new environmental snapshot and scenario revision. Existing frames remain attached to their previous revision. Hiding a map layer never calls this route.

Official references reviewed: [WorldCover data and licence](https://esa-worldcover.org/en/data-access), [Copernicus AWS catalogue](https://registry.opendata.aws/copernicus-dem/), [Copernicus raster layout](https://copernicus-dem-30m.s3.amazonaws.com/readme.html), [Open-Meteo API](https://open-meteo.com/en/docs), [Overpass API](https://wiki.openstreetmap.org/wiki/Overpass_API). Access date: 14 November 2026.

Single Runs initialisation time is preserved in provenance and is not represented as publication time. Since exact original publication availability was not provided, issuedAt conservatively uses retrieval time. These retained archived requests therefore support explicitly retrospective experiments, not a claim that the data were knowable at the initialization instant.

The single worker checks weather cadence once per minute. It schedules bounded hourly refreshes only for the newest administrator-prepared sample=false snapshot per bounds with real Open-Meteo forecast provenance and weather valid within48 hours. Historical, demonstration and override weather are excluded. Stable environment/hour job IDs deduplicate scheduling; at most four refresh jobs can be pending. Imports create new immutable snapshots and update a bounds-keyed cache; existing scenario inputs never change. Source-array inspection is bounded to200 recent real snapshot metadata records and does not load terrain cells into the scheduler.
